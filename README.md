# Mente & Comportamento

> Portal científico de psicologia cognitiva, neurociência e comportamento humano — com rigor acadêmico e linguagem acessível.

🌐 **[psicologia-site.vercel.app](https://psicologia-site.vercel.app)**

---

## Sobre o projeto

**Mente & Comportamento** é um portal de divulgação científica dedicado à psicologia e às ciências do comportamento. Todo o conteúdo é baseado em pesquisas publicadas em periódicos revisados por pares, com referências primárias e links DOI para as fontes originais.

O site foi desenvolvido como uma aplicação de página única (SPA) — rápido, sem carregamentos entre páginas e sem dependências externas além das fontes tipográficas.

## Tecnologia

- **HTML · CSS · JavaScript** — aplicação de página única sem frameworks
- **Google Fonts** — DM Serif Display, DM Sans, DM Mono
- **Vercel** — deploy contínuo via GitHub

Nenhuma dependência de pacotes externos. O site inteiro vive em um único arquivo `index.html`.

## Deploy

O repositório está conectado ao **Vercel**. Qualquer commit na branch `principal` dispara um novo deploy automaticamente.

```
Editar index.html → Commit no GitHub → Deploy automático (~30s)
```
